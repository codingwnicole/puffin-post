# Follow-up audit fixes

All four findings from the Ponytail audit were addressed on `fix/ui-wheel-polish-20261124`. No new dependencies, schema migration, production configuration changes, push, or deployment.

- **Unsaved draft writing:** Archive/Mark wrapped sends the current notes with the state change. Notes are disabled while saving, and the backup clears only after the request succeeds. The browser regression verifies the actual archive payload includes newly typed writing.
- **Account upload cleanup:** Delete every page under both character and planner prefixes. Run cleanup before the database deletion, so an object-store failure leaves the account and session available for retry. Route-level tests verify a failed cleanup does not run the deletion batch or clear the cookie, and a retry completes. Object storage and SQL cannot roll back together: an interrupted deletion can already have removed some uploads; retry finishes the requested deletion.
- **Notification failures:** Catch errors per device; one unreachable device no longer stops the rest. Failed scheduled deliveries become eligible again after one hour using the existing timestamp and 12-hour eligibility window. Eligible devices are processed oldest first. No new delivery-state schema is required.
- **Draft character consistency:** Normalize list and legacy assignments using the same precedence as draft creation. Update the primary field and link rows in one transaction. Conditional child writes protect already-converted drafts. Tests execute the actual migration schema and repository SQL against an in-memory SQLite database, including forced rollback and converted-draft protection.

Verification: production build and TypeScript passed; all 128 unit tests and 24 focused UI checks passed. Unit coverage includes cleanup pagination/retry, deletion ordering, notification continuation/backoff, and real-SQL assignment consistency/rollback. The targeted Cloudflare integration suites were attempted but cannot initialize the local Worker under this environment's socket restrictions; lifecycle teardown then also reports an absent fixture. Those integration checks still require an unrestricted environment. No lint script exists in this repository.
